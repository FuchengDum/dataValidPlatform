# 通用数据验证工具评审提交材料索引

## 提交主张

通用数据验证工具以结构化规则和确定性执行保障核验可信，以受控 AI
提升规则配置与异常分析效率，并通过 Web 工作台与 CLI 双入口分别服务
交互核查和工程化扩展。

本目录是面向评审的统一材料入口。仓库根目录既有文档继续保留，用于
呈现研发过程与演进轨迹；若历史表述与本目录存在差异，以本目录对当前
成果和边界的说明为提交口径。

## 当前成果边界

- 已实现：Web 交互式核验与展示、CLI 通用规则执行、规则模板与推荐、
  AI/本地降级分析、只读 SQL 草案、报告输出、CLI 机器可读输出基础。
- 已具备接入基础：通过 CLI 退出码、JSON 与 JUnit XML 输出对接脚本或
  流水线质量判断。
- 未作为已交付成果承诺：Web 真实生产业务库接入、完整质量门禁专项、
  Excel 格式报告、AI 自动判定或自动修改数据、Web 与 CLI 完全相同的
  规则执行链路。
