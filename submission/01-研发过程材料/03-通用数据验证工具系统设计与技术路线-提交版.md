# 通用数据验证工具系统设计与技术路线（提交版）

## 1. 总体架构

```text
                     通用数据验证工具
                            |
          +-----------------+-----------------+
          |                                   |
     Web 工作台入口                       CLI 工程化入口
  Vue 3 + REST API              init / lint / run / validate / recommend
          |                                   |
          +----------- 应用与通用规则能力 -----+
                 规则绑定 / 模板执行 / AI 辅助 / 报告输出
                            |
              H2 演示业务表 / 文件源 / JDBC 只读源
```

Web 与 CLI 服务同一个产品目标：以业务规则发现可追溯的数据疑点。二者目前
采用不同入口资产以控制迭代风险，后续可继续收敛规则资产复用范围。

## 2. Web 工作台设计

Web 采用 Vue 3 + Vite 前端和 Spring Boot REST API，面向交互核查。

| 模块 | 能力 |
|---|---|
| 数据加载 | 上传赛题 Excel 规则资产，结合 H2 seed 业务表建立数据集 |
| 规则工作台 | 展示绑定、模板能力、AI/本地模板推荐与人工应用 |
| 校验汇总 | 规则数、异常数、严重/警告分布、耗时 |
| 异常详情 | 实际值、期望值、原因、影响、建议及证据 |
| AI 辅助 | 异常分析、只读校验 SQL、人工核查 SQL |
| 报告 | 生成并下载当前已支持的报告格式 |

演示锚点选择支付链路：`R020` 展示跨订单和支付金额核对，`R029`
展示同订单重复支付风险。

## 3. CLI 通用化设计

CLI 与后端复用规则执行和 AI 辅助能力，面向扩展与自动化执行。

| 能力 | 实现用途 |
|---|---|
| `init jdbc` | 生成 JDBC 接入样板 |
| `lint` | 校验配置、模板、表字段引用及修复提示 |
| `run` / `validate` | 加载数据源和规则包，执行确定性校验 |
| `recommend` | 生成可审阅的规则候选与推荐说明 |
| 输出契约 | JSON/报告/JUnit 及退出码，供脚本消费 |

通用性主证据使用 `examples/generic-jdbc/`：该样例通过只读 H2/JDBC
加载非订单领域的 `contract_bill` 和 `payment` 表，并用通用模板规则
检出应收金额异常。`examples/case5-seed/` 用于固定复现赛题规则规模与
统计结果。

## 4. 规则执行与 AI 路线

### 确定性执行

- Web 演示链路保留模板绑定与内置规则兜底，以保障既有交互稳定。
- CLI 通用链路使用 YAML 规则包和结构化模板执行器，以支持新业务扩展。
- 常见模板覆盖非空、非负、数值类型、行表达式、跨表存在、关联断言、
  聚合一致性和重复校验等规则类型。

### 受控 AI

- 异常分析输入包含规则、异常记录和证据；输出用于人工理解和核查。
- SQL 草案必须通过只读安全要求，只生成文本预览，不具备自动执行语义。
- 规则推荐仅产生候选，正式规则资产仍由人工审阅后维护。
- 模型不可用或结果非法时返回本地规则化结果，保持核心流程可运行。

## 5. 数据流

### Web 交互核查流

```text
上传规则资产 -> 读取演示业务表 -> 保存规则绑定与数据集
-> 执行校验 -> 查看支付异常及证据 -> AI/SQL 辅助 -> 导出报告
```

### CLI 通用扩展流

```text
选择/生成数据源与规则包 -> lint 校验资产
-> run/validate 执行 -> 输出报告或 JSON/JUnit
-> 可选 recommend 生成候选规则供人工采用
```

## 6. 兼容边界与演进方向

当前不强行将 Web 与 CLI 合并为单一规则入口：两条链路分别保障现有演示
体验和通用扩展能力，验收时分别提供证据，不要求异常逐条一致。

工程化演进方向包括：

- 将更多规则资产迁移为结构化模板配置。
- 基于 CLI 已有退出码和机器输出补充质量门禁摘要及 CI 模板。
- 在安全边界明确的前提下扩展业务只读数据源和 Web 通用规则入口。
