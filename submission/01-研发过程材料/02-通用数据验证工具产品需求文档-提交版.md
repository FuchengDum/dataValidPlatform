# 通用数据验证工具产品需求文档（提交版）

## 1. 产品定位

通用数据验证工具用于基于业务规则核验测试数据、演示数据或只读接入的
业务数据，输出异常疑点、证据、原因分析和人工核查建议。

产品提供两种互补入口：

- **Web 工作台**：提供简洁直观的交互核查体验，适合业务理解、问题排查
  和评审演示。
- **通用 CLI**：提供规则配置化、数据源扩展和脚本化执行能力，适合研发
  测试工程化使用及后续质量门禁接入。

## 2. 用户与成功标准

| 用户 | 使用方式 | 需要完成的任务 |
|---|---|---|
| 测试/业务人员 | Web | 执行校验、筛选异常、理解影响、导出结果 |
| 开发人员 | Web/CLI | 核查证据与 SQL 草案、扩展验证规则 |
| 工程化人员 | CLI | 校验配置、运行规则包、消费机器可读结果 |
| 评委 | Web + 结果附件 | 判断业务价值、创新性和可复现性 |

成功标准：

1. Web 能展示赛题5支付对账风险及证据链。
2. CLI 能在非订单 JDBC 样例上执行通用模板规则。
3. Case5 固定样例能够通过 CLI 复现规则执行规模与异常统计。
4. AI 辅助结果有来源标识、安全边界和降级路径。
5. 评审材料区分当前实现、接入基础与后续规划。

## 3. Web 使用场景

Web 工作台围绕赛题5演示数据提供：

1. 加载 Excel 规则资产和 H2 seed 业务数据。
2. 展示 5 张业务表、30 条规则与校验汇总。
3. 按严重等级、数据表和规则编号筛选异常。
4. 查看 `R020` 支付金额核对异常与 `R029` 重复支付异常。
5. 查看实际值、期望值、原因、影响、建议和证据链。
6. 触发 AI/本地降级分析和只读 SQL 草案生成。
7. 导出 Markdown 或 HTML 报告。

## 4. CLI 使用场景

CLI 面向通用化和自动化使用，公开命令包括：

```bash
bin/data-validator init jdbc --output demo-dir
bin/data-validator lint --config validator.yml
bin/data-validator run --config validator.yml --json --no-report
bin/data-validator validate --rules rules.yml --source source.yml --output reports
bin/data-validator recommend --rules rules.yml --metadata source.yml --output recommendations.json
```

CLI 需求包括：

- 支持 YAML/JSON 规则资产与配置校验。
- 支持文件数据源和只读 JDBC 样例。
- 支持结构化模板规则、规则片段复用和候选推荐。
- 支持 JSON、Markdown、HTML 或 JUnit XML 等已实现输出形态，以具体配置
  与命令为准。
- 以退出码表达执行结果：`0` 正常且未触发严重阈值，`1` 执行失败，
  `2` 检出达到失败等级的异常，`3` 配置或规则非法。

## 5. 可信规则智能化需求

| 能力 | 要求 |
|---|---|
| 规则资产 | 优先沉淀为结构化模板和规则包，避免新增业务规则继续硬编码 |
| 最终判定 | 由确定性执行器完成，AI 不作为判定依据 |
| AI 分析 | 基于异常和证据生成原因、影响、建议；失败时可降级 |
| AI 推荐 | 生成候选规则及差异，必须经人工确认后才能纳入正式规则 |
| SQL 草案 | 只返回人工核查用 SQL，不自动执行或修改数据 |
| JDBC | 以只读接入方式使用，不在提交材料中承诺生产写入能力 |

## 6. 当前范围与非目标

### 已实现或已有实现证据

- Web 工作台及其后端 API 的上传、校验、详情、AI 辅助和报告导出能力。
- CLI 通用规则执行、配置检查、推荐入口、文件/JDBC 样例和报告输出。
- Case5 CLI 固定复现样例及通用 JDBC 扩展示例。
- SQL 只读安全校验和 AI 不可用时的本地降级。

### 不作为当前成果承诺

- Web 真实生产业务库输入。
- 完整质量门禁、`gate-summary`、覆盖趋势和正式 CI workflow。
- Excel 格式报告。
- AI 自动判定、自动执行修复 SQL 或自动修改业务数据。
- Web 与 CLI 规则来源、执行路径和异常集合完全统一。

## 7. 评审验收

评审验证由三部分构成：

1. Web 现场展示支付对账风险与异常解释闭环。
2. CLI 运行 `generic-jdbc` 样例，展示通用规则扩展和只读数据源接入。
3. CLI 运行 `case5-seed` 样例并核对固定统计，证明成果可复现。
