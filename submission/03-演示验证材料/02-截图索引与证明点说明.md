# 截图索引与证明点说明

## 1. 补录规则

截图必须来源于真实运行界面或真实命令执行结果。文件建议放入同目录的
`screenshots/`，命名采用 `S01-*.png` 格式，并在补录后填写本表中的文件名
与采集日期。

## 4. 安全证据页素材

安全证据页至少组合以下信息：

| 证据 | 说明 | 状态 |
|---|---|---|
| SQL 草案 `executable=false` 或页面安全提示 | 系统只生成核查草案 | 待补录 |
| 模型降级 warning 或来源标识 | 非法/不可用模型结果不会影响核心流程 | 待补录 |
| JDBC 样例与只读账号说明 | 接入业务库遵循只读边界 | 已有文档依据，待排版 |
| `recommend` 候选路径 | 不自动覆盖正式规则资产 | 待补录 |
