## 4. 通用 JDBC 场景

当前 JDBC 样例的 H2 初始化脚本相对 `backend/` 目录解析。本机实测时，
还需将 Homebrew JDK 11 放入 `PATH`：

```bash
cd backend
PATH="/opt/homebrew/opt/openjdk@11/bin:$PATH" \
  ../bin/data-validator lint --config ../examples/generic-jdbc/validator.yml
PATH="/opt/homebrew/opt/openjdk@11/bin:$PATH" \
  ../bin/data-validator run --config ../examples/generic-jdbc/validator.yml --json --no-report
```

`lint` 关键输出：

```json
{
  "valid": true,
  "errors": [],
  "warnings": []
}
```

`run` 关键结果：

```json
{
  "exitCode": 2,
  "totalRules": 2,
  "executedRules": 2,
  "findingCount": 1,
  "criticalCount": 1,
  "warningCount": 0,
  "sourceSummary": {
    "type": "jdbc",
    "tableCount": 2,
    "totalRows": 3
  },
  "reports": {}
}
```

解释：退出码 `2` 对应该样例故意设置的严重异常，证明非订单 JDBC 场景
可以由通用规则包完成校验。

## 6. 规则候选推荐

命令：

```bash
bin/data-validator recommend \
  --rules examples/generic-validation/rules.yml \
  --metadata examples/generic-validation/source.yml \
  --output /private/tmp/data-validator-recommendations.json \
  --candidate-rules /private/tmp/data-validator-rules.recommended.yml
```

本轮关键结果：

```json
{
  "ruleId": "C900",
  "templateCode": "ROW_EXPRESSION",
  "confidence": "HIGH",
  "source": "LOCAL_RULE_BASED",
  "generatedByAi": false,
  "requiresHumanReview": true,
  "candidateGenerated": true,
  "warningCategories": ["人工确认必需"]
}
```

解释：当前未依赖模型即可生成本地候选规则，并明确要求人工确认；输出在
临时新文件中，不覆盖仓库正式规则包。模型生成结果与 Web 来源标识截图
仍需在启用演示模型后真实补录。
